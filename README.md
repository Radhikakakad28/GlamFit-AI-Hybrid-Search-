# GlamFit.AI – Hybrid Semantic Fashion Search & Recommendation Platform

## Overview
GlamFit.AI is a scalable AI-powered fashion intelligence system integrating:

- Hybrid Semantic Search (BM25 + Transformer Embeddings)
- FAISS Vector Indexing
- Personalization Engine
- Popularity-based Recommendation System
- BERT-based Sentiment Analysis
- Fake Review Detection (Logistic Regression)

## Dataset
Custom 2000+ fashion product dataset inspired by H&M e-commerce structure.

## Tech Stack
- Python
- Sentence Transformers
- FAISS
- Scikit-learn
- HuggingFace Transformers
- Pandas, NumPy

## Key Features
- Weighted hybrid ranking
- Adaptive re-ranking based on user preferences
- Popularity scoring
- Review intelligence module
- AI-driven commerce system design
